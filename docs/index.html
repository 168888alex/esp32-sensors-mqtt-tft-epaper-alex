PROJECT OVERVIEW

一條從感測到控制的完整學習路徑

每個資料點都能被讀取、傳送、顯示與控制，從基礎範例逐步整合成可展示的物聯網作品。

01

即時感測

DHT11 讀取溫度與濕度，光敏電阻讀取環境亮度，電子紙每 60 秒更新。

02

MQTT 傳輸

以 JSON 發布 temp、humi、light 與感測器有效狀態。

03

遠端控制

訂閱三個 MQTT topic，控制綠、黃、紅三路 LED。

HARDWARE MAP

微雪 2.9 吋三色電子紙

使用 V4 / Rev2.1 模組，橫向解析度 296×128。腳位統一後，適合課程重複使用與快速換版。

296 × 128 px紅 · 白 · 黑ESP32 Dev Module
電子紙DIN / MOSI GPIO23SCK GPIO18CS GPIO27DC GPIO26RST GPIO25BUSY GPIO34
感測與燈號DHT11 GPIO14光敏電阻 GPIO33綠 / 黃 / 紅 LED 15 / 2 / 4

MQTT CONNECTION

資料發布，控制訂閱

Broker 使用 mqttgo.io:1883。以下設定與目前的 40_epaper_mqtt 完整對應。

sensor payload
{
  "temp": 25,
  "humi": 60,
  "light": 75,
  "dhtValid": true,
  "lightValid": true
}
綠燈控制alex/class301/ctrl/gled
黃燈控制alex/class301/ctrl/yled
紅燈控制alex/class301/ctrl/led4

控制 payload：{"state":"on"} 或 {"state":"off"}

DISPLAY DESIGN

紅、白、黑，讓資訊清楚留下

圖示、數字與單位分欄配置；感測器失效時以紅色驚嘆號提示，確保電子紙在低功耗情境下仍能快速辨識。
